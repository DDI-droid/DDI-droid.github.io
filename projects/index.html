Projects

Research and things I have built. Blog links where a write-up exists.

Research

  • Policy Language Models — a meta-reasoning inference paradigm: the LLM reasons about the goal on its trajectory and expresses its computation as policies in a persistent REPL, instead of grinding everything inline. My main current work.

  • PolyTM — a reinforcement learning environment where a neural network learns to write the computation that solves a problem, tape machines, add/multiply instructions, rewards for correct results in polynomial time.

  • ForTest — a forecasting benchmark and evaluation harness: drop in a custom LLM agent and test it on financial forecasting tasks with temporal isolation, so no agent quietly reads the future.

  • Forecasters — LLM forecasting agents built at Kairosity, the line of work behind our GIFT-Eval and ProphetHacks results.

Systems

  • AFramework — an agent framework that separates applications from LLM inference: a self-starting daemon that runs agent tasks across worker processes with cost-based routing, rate limits, verifiers, and durable results.

  • Table OCR with RL — training a network to repair a table detector’s bounding boxes on financial documents, geometric rewards in the open version, a vision-model judge in the applied one. Built at Decimal Point Analytics.

  • UAV pathfinding with reinforcement learning — path planning for UAVs learned end to end with RL.

Kairosity

  • Boltzmann — a synthetic consumer panel for testing product concepts on Indian consumers. Upload a brief and an agent stack extracts the concepts, researches competitors and cultural priors, samples ~100 synthetic personas per concept, surveys them, clusters the responses by belief, and writes the report.

  • Risk Terminal — an AI risk intelligence platform combining causal discovery, multi-agent probabilistic forecasting, Monte Carlo simulation, and real-time monitoring, so you learn what drives a risk, not just its number.
