# LessWrong feature comparison: confirmed gaps only

This is a comparison of the current static site and `_writer` with relevant ForumMagnum source at commit [`06c4414`](https://github.com/ForumMagnum/ForumMagnum/tree/06c4414a2e5343caa37ff55605c0f27915a2d105). It is a list, not an implementation plan. A source-tree file proves that code exists in that revision; it does **not** prove a feature is enabled for every LessWrong user or page in production.

Already present, and therefore not listed as gaps: heading-based contents rail/scroll progress, math, footnotes with sidenotes/hover cards/dialog, spoilers, collapsibles, image figures/captions/resizing, tables, code-block rendering/highlighting, and YouTube video embeds. See `_layouts/post.liquid`, `_writer/render.js`, `_writer/static/bridge.js`, and `_writer/README.md`. The site also has search and RSS; those are not gaps.

## Static versus service boundary

The source-only features that can work in a static page include code-copy UI, a tooltip backed by a bundled glossary, fixed sequence links/order, and playback from a known audio URL. Features that depend on user accounts, shared mutable content, authenticated editing, notification delivery, external metadata fetching/caching, moderation, or persistent votes/comments require a backend or a third-party service. This distinction describes technical requirements, not a recommendation to add any of them.
